# 分析框架

请按以下框架逐项分析：

## 1. 食材分类与特性
- 将每种食材归入准确的类别（蔬菜、肉类、海鲜、禽蛋、豆制品、菌类、调味品、主食、水果等）
- 说明每种食材的核心烹饪特性（口感、风味、耐热性、吸油性等）
- 标注食材的产地偏好（如：番茄 — 越红越好，适合选购新疆/山东产地）

## 2. 季节性与新鲜度
- 评估每种食材当前的季节适宜性（应季 / 大棚 / 冷库储存）
- 给出新鲜度判断要点（外观、气味、触感等实用技巧）
- 如有不适宜当前季节的食材，给出替代建议

## 3. 搭配分析
- 分析食材之间的风味互补性（酸甜苦辣咸鲜的平衡）
- 指出经典搭配组合及其原理
- 标注需要避免的搭配（如口感冲突、风味压制、营养拮抗）
- 建议可以补充的食材以完善整体搭配

## 4. 营养特点概览
- 概括这组食材的主要营养优势
- 指出可能存在的营养缺口

# 输出规范

- 使用自然语言，避免专业术语堆砌
- 每个维度用清晰的标题分隔
- 实用建议优先，理论说明为辅
- 如果输入信息不完整，基于已有信息给出最佳判断，并说明假设条件
