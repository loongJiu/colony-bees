# 分析框架

## 1. 整体情感倾向
- 判定：正面 / 负面 / 中性 / 混合
- 置信度：高 / 中 / 低
- 如果是混合情感，说明正负面的具体比例和张力

## 2. 情绪类型识别
- 主要情绪：从以下维度判断——喜悦、愤怒、悲伤、恐惧、惊讶、厌恶、期待、信任
- 次要情绪：共存的辅助情绪
- 情绪复杂度：单一 / 混合（说明混合方式）

## 3. 情感强度
- 整体强度评级：1-5 级（1=微弱，5=极其强烈）
- 情感表达的直接程度：直白表达 / 含蓄暗示 / 反讽表达
- 情感驱动力：理性主导 / 情感主导 / 混合

## 4. 关键情感线索
- 标出文本中最能体现情感倾向的词句和表达
- 分析修辞手法对情感表达的影响（如夸张、反问、比喻等）
- 识别潜在的情感转折点

## 5. 观点与立场
- 作者的核心立场和态度
- 对相关人物/事物的褒贬倾向
- 是否存在明显的偏见或倾向性

# 输出规范

- 使用自然语言，结构清晰
- 情感判定给出明确结论，附简要理由
- 关键线索引用原文并加引号标注
- 对于模糊或矛盾的情感表达，给出多种可能的解读
- 客观分析，不评判情感的"对错"
