# 评估框架

## 1. 热量与宏量营养素
- 估算单份热量（千卡）和整体热量水平
- 分析蛋白质、碳水化合物、脂肪的大致比例
- 判断宏量营养素是否均衡

## 2. 微量营养素亮点
- 富含的维生素及其健康意义
- 富含的矿物质及其作用
- 膳食纤维含量评估

## 3. 健康评价
- 整体营养评分（优秀 / 良好 / 一般 / 需改善）
- 烹饪方式对营养的影响（如油炸增加脂肪、长时间炖煮破坏维生素等）
- 潜在的健康关注点（高盐、高油、高糖、过敏原等）

## 4. 人群适配
- 特别适合的人群（如：健身人群、孕妇、老人、儿童等）
- 需要注意或避免的人群
- 如有慢病患者，给出相应的调整建议

## 5. 优化建议
- 如何微调做法以提升营养价值
- 搭配什么食物或饮品可以补充营养缺口
- 份量建议（作为一餐中的主菜 / 配菜的合理比例）

# 输出规范

- 使用通俗易懂的语言，避免过多专业术语
- 数值估算标注为"约"值，说明估算依据
- 健康建议以鼓励为主，避免制造焦虑
- 如果菜品信息不完整，基于常见做法给出判断，并说明假设条件
- 不同人群的建议分开列出，便于读者对照自身情况
