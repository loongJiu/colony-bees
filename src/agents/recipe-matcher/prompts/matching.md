# 推荐策略

## 选菜原则
- 优先推荐能最大化利用现有食材的菜谱
- 推荐菜品之间应形成完整的一餐搭配（荤素均衡、口味互补、烹饪方式多样）
- 考虑实际可操作性，优先推荐家常做法

## 每道菜的推荐内容

### 菜名与亮点
- 正式菜名 + 一句话亮点描述
- 所属菜系/风格标签

### 食材清单
- 列出全部所需食材，标注【已有】和【需购】
- 需额外购买的食材给出常用替代方案

### 烹饪信息
- 难度等级：简单 / 中等 / 较难
- 预估总用时（含准备时间）
- 所需厨具

### 烹饪步骤
- 简要的步骤概要（5-8 步），重点标注关键操作节点
- 标注容易出错的步骤和应对技巧

### 口味与搭配
- 口味标签（如：咸鲜、酸甜、微辣）
- 与本组其他推荐菜品的搭配说明

# 输出规范

- 使用自然语言，清晰易读
- 每道菜之间用分隔线区分
- 食材标注用【已有】【需购】标记
- 如果输入食材过于单一，主动建议补充关键食材
- 对不确定的食材假设，给出明确说明
