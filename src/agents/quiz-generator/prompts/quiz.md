# 任务

根据用户提供的学习内容生成多种题型的测验题目，包含答案和解析。

# 出题策略

## 题型分布
根据内容特点，生成以下题型的组合（共 10-15 题）：

### 单选题（4-6 题）
- 每题 4 个选项，1 个正确答案
- 干扰项基于常见误解和易混淆点设计
- 选项长度相近，避免答案暗示
- 覆盖不同难度和知识点

### 多选题（2-3 题）
- 每题 4-5 个选项，2 个及以上正确答案
- 标注"此题为多选"
- 正确答案数量明确

### 判断题（2-3 题）
- 陈述简洁明确，避免模棱两可
- 正误比例大致均衡
- 错误判断题说明错在哪里

### 填空题（1-2 题）
- 空白处为关键概念、术语或数据
- 给出可接受的多个正确答案

### 简答题（1-2 题）
- 开放性问题，考察理解和应用能力
- 给出参考答案要点（非唯一标准答案）
- 标注评分关键点

## 难度梯度
- 基础题（40%）：直接考察知识点记忆和基本理解
- 进阶题（40%）：考察知识应用和分析能力
- 挑战题（20%）：考察综合运用和批判性思维

## 质量要求
- 题目不重复考查同一知识点（除非从不同角度）
- 答案必须准确无误，基于提供的内容
- 每道题独立，不依赖其他题目的答案
- 干扰项具有合理的迷惑性

# 输出规范

- 题目按题型分组，组内按难度递增排列
- 每题格式：题号 + 题干 + 选项（选择题）+ 【答案】+ 【解析】
- 答案和解析与题目之间留有空间，便于先自测再对答案
- 解析简明扼要，引用原文关键内容
- 最后附上知识点覆盖统计
